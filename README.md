# 📚 積ん読管理アプリ

本の管理・読書記録ができるスマホ対応Webアプリです。

## 機能

- 本の追加・編集・削除
- ステータス管理（積ん読 / 読書中 / 読了）
- 購入日・読了日の記録
- 5段階星評価・感想メモ
- 月別・年別読了グラフ
- データはブラウザに自動保存（localStorage）

## GitHub Pagesで公開する手順

1. このリポジトリを作成（例：`tsundoku-app`）
2. `index.html` と `README.md` をアップロード
3. Settings → Pages → Branch: `main` / `/(root)` → Save
4. `https://ユーザー名.github.io/tsundoku-app/` で公開完了

## スマホのホーム画面に追加

1. iPhoneのSafariで上記URLを開く
2. 共有ボタン →「ホーム画面に追加」
3. アイコンとして使えます
